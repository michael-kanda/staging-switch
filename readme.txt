Create a staging copy of any page or post, keep it noindex, share it with clients by private link, and switch it live with one click.

== Description ==

* Create a staging copy of any page or post. Pages become child pages, for example /dog-treats/dog-treats-staging.
* Switching swaps the content. The live URL and post ID stay the same.
* Staging is always noindex and nofollow: robots meta, X-Robots-Tag header, canonical to live, excluded from sitemaps, search, menus, feeds and REST.
* Visitors without the private approval link see a 404.
* Approval link with optional expiry. Clients can approve or request changes, and you receive an email.
* Works with Yoast SEO, Rank Math, All in One SEO or no SEO plugin, and with any page builder because post meta is swapped unchanged.
* The live page is marked with a green LIVE badge in the list and in the editor.
